# MoneyDropPNX [![Discord](https://img.shields.io/badge/chat-on%20discord-7289da.svg)](https://discord.gg/HVvQv2TxWs)
With MoneyDropPNX you can easily give money to all players who are on the server

## Commands + Permission
Command | Description | Default | Alias                     | Permissions
--------- | ------------------- | ------- |---------------------------| -----------
``/moneydrop`` | ``Make a money drop`` | ``true`` | ``moneyd`` ``mdrop`` ``md`` | ``moneydrop.command``
